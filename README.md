# VR Arm IK & Kinetic Recorder

Unity-based virtual reality prototype for upper-limb motion tracking,
inverse kinematics, and movement data collection.

## Overview

This project explores VR-based upper-limb interaction and kinematic
recording using Unity. It was developed as part of my work in immersive
interaction and rehabilitation technologies.

## Technologies

- Unity
- C#
- Virtual Reality
- Inverse Kinematics
- Motion Tracking
- VRTK
- Real-time data recording

## Features

- VR upper-limb tracking
- Inverse-kinematics arm representation
- Motion and position data recording
- Real-time interaction
- Experimental data collection

## My contribution

I designed and implemented the Unity application, interaction logic,
motion tracking, inverse-kinematics integration, and data recording
pipeline.

## Related work

My later research focused on immersive VR systems for post-stroke
upper-limb rehabilitation.
